# Archivist — design contract v0.1.0

## Principle
**Memory of evidence, not authority.** No retrospective inference is used as owner instruction or release permission. The evidence trail is event-sourced; append new correction events rather than rewriting history. Ingestion availability depends on a real connector, explicitly provided transcripts, or exported chat archives; independent plugins do not automatically see other ChatGPT conversations.

## Core indices
1. `projects`: project_slug, approved name, goals, non-goals, source anchors.
2. `events`: append-only event_id, mission/project, UTC observed record time, optional occurrence time + precision + timezone, original source, assertion kind, confidence, release/approval state, sensitivity, summary, evidence snippets.
3. `decisions`: requested / proposed / owner-approved (exact version+action+artifacts) with supersession chain.
4. `artifacts`: exact named outputs, links, tool events, hashes and quality gates.
5. `tasks`: blockers, assigned roles, state transitions, evidence and accepted next actions.
6. `signals`: owner-authorised tentative shifts in writing tone, project direction, expressed urgency/motivation, annotated with source coverage and alternative explanations.
7. `context_packets`: who asked, which project/mission, purpose, included and withheld evidence links, generation time.

## Event ingest contract
See `examples/event.json`. `occurred_at` UTC optional, `time_precision` one of exact/minute/date/sequence/unknown. `recorded_at` is generated by host clock. Never use `recorded_at` as if it were the utterance time. `verified_status` independently distinguishes user self-report from verified tool outcome. `visibility` `council` or `owner_only`, `sensitivity` `ordinary` / `personal_analytics` / `sensitive`; personal analytics are owner-only by default. External source connector scope requires an explicit authenticated grant.

## Source accuracy
Original user messages are source truth for intent, not proof that technical work actually happened. Agent message 'deployed' is claim until verified using tool ID + checksum + destination. Include conflicts and actual missing evidence in the current snapshot. Multiple timestamp precisions remain separate.

## Handoff security
Whitelist non-sensitive, council-visible records scoped to project. Internal role != authenticated human/agent; CLI role argument is descriptive and **not** a security authorization boundary. Only trusted Council host with permission broker can release secure data; the prototype returns a fail-closed omission of owner-only analytics and sensitive data to all normal role packets.

## Handoff scope
- Counterweight: original owner request provenance, revisions, permission conflicts.
- Directors: approved objectives, decisions, known project status, blockers and priorities.
- Creative Director: visuals, approved art direction, feedback, historical preference/anti-preference.
- Researcher/Northstar: verified research, objectives, context and explicit uncertainties.
- Checker: source baseline, tests, evidence, acceptance criteria, reversals and approvals.
- Executor: current authorised build specification, requirements, links and limits. Excludes behavioural profiling.
- Owner: complete consented project record plus private analytics when requested.

## Acceptance tests
T1 record time, event occurrence time and precision remain distinct. T2 role-scoped handoff never returns owner_only or sensitive. T3 changes preserve source lineage. T4 inconsistent release claims do not become approved. T5 duplicates reject by source_key. T6 no connector or chat history claims. T7 archives read-only source and never auto-approve. T8 integrity digest chain validates and detects after-the-fact row mutations in local prototype (not tamper-proof vs database admin).

## Rollout gate
Draft candidate only. Do not update existing Council registry or other plugin versions until owner approves an exact patch and owner-scoped source write. Standalone private installation ≠ authorisation to harvest historical or future chats, change permissions or publish externally.
